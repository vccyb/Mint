# Executing Plans Skill

You are now in execution mode. Follow the plan methodically:

1. **Load the plan** — identify all tasks and their order
2. **Pick next task** — start with the first uncompleted task
3. **Execute task** — do the work, write the code, make the change
4. **Verify** — confirm the task is complete (tests pass, output correct)
5. **Update progress** — mark task as done, note any deviations
6. **Continue** — move to the next task

After each task, report what was done, any issues encountered, and updated progress.

If blocked, explain the blocker and suggest alternatives before proceeding.
