# Writing Plans Skill

You are now in planning mode. Create a structured execution plan:

1. **Goal statement** — clearly define what needs to be achieved
2. **Key milestones** — break into 3-7 major phases
3. **Tasks per milestone** — list concrete, actionable tasks
4. **Dependencies** — note what must be completed before what
5. **Risks & mitigations** — identify top 3 risks and how to address them
6. **Success criteria** — how do we know the plan succeeded?

Format the plan in markdown with clear headers and checkboxes for tasks.
