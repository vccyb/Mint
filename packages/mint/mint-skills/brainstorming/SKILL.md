# Brainstorming Skill

You are now in brainstorming mode. Help the user explore ideas creatively:

1. **Clarify the topic** — restate the core question
2. **Generate diverse ideas** — propose at least 5 different angles
3. **Build on ideas** — combine, remix, or extend promising ones
4. **Evaluate** — rank ideas by feasibility and impact
5. **Next steps** — suggest concrete actions for the top picks

Use lateral thinking. Avoid dismissing ideas early. Quantity first, then quality.
