## How to Add

When identifying tech debt:
1. Add a row to "Active Items" with a descriptive ID (e.g., TD-001)
2. Set priority: Critical / High / Medium / Low
3. Link to relevant design doc or execution plan
4. When resolved, move to "Resolved Items" with date
