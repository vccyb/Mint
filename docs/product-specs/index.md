## Creating New Specs

When creating a product spec:
1. Use naming convention: `kebab-case.md` or numbered `NNNN-kebab-case.md`
2. Add an entry to this index
3. Follow the spec template below

## Template

```markdown
# [Feature Name]

**Status:** Draft | In Review | Approved | Implemented
**Priority:** P0 | P1 | P2 | P3
**Owner:** [team/person]

## Overview
[One paragraph description]

## Requirements
- [ ] Functional requirement 1
- [ ] Functional requirement 2

## Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2

## Dependencies
- [List any dependencies]

## Open Questions
- [List unresolved questions]
```
